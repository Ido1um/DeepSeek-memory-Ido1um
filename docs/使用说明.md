# 使用说明（给人看的）

不用懂代码，照下面做就行。全部操作都在**本机**完成。

## 一、这东西在干嘛

想象一个笔记本：

- 今天说的话，先记在**最近 7 天**的流水账里（随时能翻原文）；
- 从中挑出**值得长期记住**的——生日、喜好、答应过的事——记成一条条「事实」；
- 事实放久了会淡：常被提起的越来越牢，没人提的慢慢沉底（但**不会真的删掉**，还能搜到）；
- 每次开新对话，只把一张**最多 2000 字的事实卡**给模型看，而不是把几百页聊天记录塞进去。

## 二、每天你会看到什么

| 时间 | 发生什么 |
|---|---|
| 平时 | 每条消息进流水账；提到旧事实会加一点「记忆强度」 |
| 每天 23:00 | 归档出窗口的日志 → 结算分数 → 重排事实卡（备份旧卡） |
| 快到截止日 | 提前一天推一条提醒（如果设置了截止时间） |
| 上下文快满 | 到窗口 70% 时换一个新会话，并把事实卡 + 最近 7 天摘要带过去 |

## 三、打开工作台

双击 `workbench\start.cmd`，或命令行：

```bash
node workbench/server.mjs --port 7351
```

浏览器打开 `http://127.0.0.1:7351`，默认落在**记忆星图**。

![星图](screenshots/starmap.png)

星星怎么读：

| 颜色 | 含义 |
|---|---|
| 橙色大点 | 用户（人物节点） |
| 墨绿 | 硬事实（生日、名字、称呼…永不淡忘） |
| 蓝 | 长期 |
| 棕 | 一般 |
| 灰 | 主题（生日 / 喜好 / 学业工作 / 住处…） |
| 紫 | 截止日 |

- 鼠标**拖动**：转视角；**滚轮**：拉近拉远；**点一颗星**：下方显示它记着什么
- 左上「全部 / 只看硬事实 / 待办」：过滤
- 「重排」：打散位置重新布局（数据不变）
- 「设置」：回到常规面板

## 四、想看/想改记忆

点左边「长期事实」，每一行右边有三个东西：

```
[档位下拉]  [分数输入]  [存]   [作废]
```

- **改档**：`hard` 永不衰减 / `long` 30 天 / `general` 3 天 / `temp` 1.5 天
- **改分**：0–100，直接顶替你看到的那条
- **存**：写进事实库（会有审计记录，可以撤回）
- **作废**：这条错了（听错、张冠李戴），标成墓碑——检索和事实卡都不再返回，但历史还在

## 五、换方案（忘得快还是慢）

「记忆方案」面板里有三档：

- **保守**：忘得慢，适合「怕丢东西」
- **均衡**（默认）：两边都不极端
- **激进**：忘得快，库里更干净

改完点「保存目标配置」，确认无误再「应用到线上」（会先备份线上配置）。

## 六、出问题怎么办

| 现象 | 先做这个 |
|---|---|
| 页面打不开 | 看命令行窗口有没有报错；端口被占会自动换，日志里有实际端口 |
| 事实卡不动 | 跑一次 `node scripts/memory-cli.mjs refresh-card` |
| 提醒没来 | `node scripts/memory-cli.mjs health` 看「日终新鲜」；确认事项有截止日期 |
| 记错了 | 「长期事实」里作废；或 `node scripts/memory-cli.mjs invalidate <id>` |
| 想整体关掉 | 配置里 `memory.enabled = false`，或工作台「调控台」总开关 |

## 七、数据在哪

默认 `~/.deepseek-memory/data`（Windows：`C:\Users\<你>\.deepseek-memory\data`）。里面有：

```
raw/hot/<日期>/     最近 7 天原文
raw/archive/<月>/   归档后的原文（永久保留）
longterm.jsonl      长期事实（事件流）
profile.md          事实卡（可读文本）
rules.md            你自己的规则（称呼、禁止、风格）
state/              分数、策略、作废墓碑等状态
logs/               日终、告警、审计
```

**备份＝直接复制这个目录**。它不含代码，可以单独拷走。
