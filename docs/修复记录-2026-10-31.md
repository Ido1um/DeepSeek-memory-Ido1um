# 修复记录 · 2026-10-31

> 对「记忆方案是否存在 bug」做了一次只读审计（代码 + 线上数据复现），结论：
> 线上在跑，但代码里有 1 条高危竞态 + 数条静默失效。本文记录修了什么、证据、验证、回滚。
> 全部改动只在源码层，没有数据格式迁移（只新增字段/事件，老行读时推导）。

## 一、修了什么（8 项）

| # | 严重度 | 问题 | 修法 | 位置 |
|---|---|---|---|---|
| 1 | 高 | 状态缓存竞态：`getState()` 1.5s 后无条件从磁盘重载，而 `saveStateSoon()` 去抖 2s；落在 1.5–2.0s 窗口内的写入会被旧值覆盖且不再重放 → 会话映射回退、`profileInjectedFor` 丢失导致卡重复注入 | 脏时不重载：`(!stateDirty && now - stateCacheAt > 1500)` | `src/store.mjs` |
| 2 | 高 | 降档「回春」：`tier` 事件把 `lastAt` 设成 now，100 天没提的 long 事实降到 general 后分数从 8 反弹到 80，永远沉不下去 | `tier` 事件只写 `updatedAt`，不碰 `lastAt`；`expire/invalidate/reinstate` 同理 | `src/longterm.mjs` |
| 3 | 高 | 主语不进 sig/topic：「我妈生日」和「我生日」都落到 `user:生日`，后一句被当成前一句的提及，值静默丢失 | 新增 `subjectTag()`：只有非自指主语（我妈/我爸/我家…）进 sig/topic；自指（我/咱/俺/你）保持老键，免迁移 | `src/facts.mjs`、`src/scoring-runner.mjs` |
| 4 | 高 | 「这/本」星期被解析成已过去日期且过点不提醒：`这周五要交` 在周五 23:14 解析成当天 09:00，落在窗口外 → 永不提醒 | `reminderWindow` 增加逾期窗口（`reminders.overdueHours`，默认 72h，0=老行为）；非法日期（2026-02-30）返回 null；支持 `9:30` 纯时刻 | `src/due.mjs`、`src/engine.mjs` |
| 5 | 中 | 四段注入只在「注入事实卡那一轮」装配：长会话第 2 轮起规则/待办/检索全无 | 改成每轮装配规则/待办/检索，卡仍只在首轮或卡更新后带 | `src/engine.mjs` |
| 6 | 中 | 工作台写 ISO 时间戳：`Number("2026-10-30T…")=NaN` → `lastAt` 每次 materialize 重置成 now，被人工调过的事实永不衰减、永远排最前 | 事件 `at` 改数字 epoch（审计日志仍用 ISO）；`materialize` 新增 `toMs()` 统一「数字/ISO」并回落旧值而不是 now；`manualReset` 同时还原 I 与 S；`update` 改期清 `notifiedAt` | `src/longterm.mjs`、`workbench/server.mjs` |
| 7 | 中 | 卡 hard 额度双扣：`take(f, max(hardCap, maxChars - total))` 里 total 已含 hard，6 条硬事实就把额度吃光 | hard 用全局 `maxChars` 记账；「我的事」仍受 `botMaxChars` 限额 | `src/card.mjs` |
| 8 | 中 | `trimLines` 跳过放不下的长行去捡后面的短行（输出不是前缀）→ 卡超预算时前面的硬事实被丢、后面的软事实留下；且预算 0 会返回全量 | 改为前缀截断（遇到第一条放不下就停）+ 预算 ≤0 返回空 + 摘掉旧尾注避免叠加 + 不切断代理对 | `src/rules.mjs` |

顺手修的低危项：
- `s: null` 不再被当成 0（按默认 3 天算）；`fact` 事件的 `hits` 不再被丢弃。
- `scoring` 配置的扁平键（`halfLifeLong` / `halfLifeGeneral` / `halfLifeTemp` / `promoteHits` / `promoteScore` / `demoteFloor`）现在真正生效；新增 `unknownScoringKeys()` 供 CLI/doctor 提示未识别键。
- `update` 事件改期后清 `notifiedAt`（否则新日期永远不提醒）。
- `health` 的端口探测改为纯 Node TCP（`src/portprobe.mjs`，三态 open/refused/blocked），不再用 `netstat` 子进程。

## 三、没修的（已知设计落差，另行排期）

- 自动抽取只覆盖少数固定属性 + 「记住…」句式：真实日志里绝大多数入站消息没有候选，mention 事件很少，导致复习加分/升档/降权长期空转。这是抽取器的能力边界，不是 bug。
- 作废连坐对 v8 的 supersede 不再产生「后代」（版本链在同一事实 id 上累加，事件流里本来就没有子 id），连坐为空是预期行为，不是失效。
- `config.contextWindowTokens` 会优先于 DSH 上报的窗口；`probePort` 只探 IPv4。
