# 路线图

按「先能跑，再好用」排。

## 已具备（1.0.0）

- 四层记忆：原文日志 / 长期事实 / 事实卡投影 / 到期提醒
- 事件流事实库 + 按类衰减 + 四档 + 三预设
- 轮转按真实 token（0.7×窗口），会话三态，事实卡投影与备份
- 作废 / 恢复（墓碑 + 审计）、改档 / 改分
- MCP 两个工具、CLI 12 个子命令、3D 记忆星图工作台

## 下一步（按优先级）

1. **DSH 直连插件**（实验）
   在 DSH 会话里直接取消息、注入事实卡、到阈值换新会话。已核实接口：`session/event`、`agent.inject`、`ctx.agents.create`、客户端 `sessions.open`；未做 POC：注入时序、自动切会话。

2. **时间轴视图**
   把 `event` 类事实按日期排成一条线（故事线不漏、不断层），星图旁边加一个「时间」模式。

3. **冲突提示**
   同一主题新旧值冲突时，在写入前给一条提示，而不是静默覆盖。

4. **导出给人看**
   一键导出「每日一页」Markdown（可被 Obsidian 等直接打开），只读，不回写。

## 不做的事

- 向量检索 / 重排模型：本项目的检索是关键词 + 档位 + 版本，够用且零依赖；引入 embedding 会把部署成本翻倍。
- 云端同步：数据是你的，放本地；要同步自己用网盘/Git。
