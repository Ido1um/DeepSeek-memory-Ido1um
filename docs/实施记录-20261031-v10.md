## 二、开关（数据目录 `v10.json`）

| 键 | 默认 | 作用 |
|---|---|---|
| `enabled` | `false` | 总开关；关闭时事件与检索输出和旧版一致 |
| `emit` | `false` | 注入文本是否按 D 分档、加 `qLabels` 前缀 |
| `rankInInject` | `false` | 检索段按激活值排序 |
| `recordRetrieved` | `false` | 是否把「真的被想起」写进事件流（同天去重、不涨分） |
| `salienceFloor` | `0` | 低于该激活值不进注入；经验值 20，0 表示不启用 |
| `qLabels` | 比较确定 / 大概记得 / 只记得片段 | 三档措辞 |

建议上线顺序：先 `enabled:true, emit:false` 只记账，观察几天 `recall --explain` 的 Q/D 分布，再开 `emit:true`。
